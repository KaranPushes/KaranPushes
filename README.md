## 🚀 Featured Projects

### 📡 1. Live Streaming Platform
A full-stack live streaming platform designed to deliver real-time video streaming with a focus on performance, scalability, and seamless user experience.

- ⚡ Built a platform for real-time live video streaming.
- 🔧 Full-stack development with frontend and backend integration.
- 🌐 Focused on streaming performance and reliable media delivery.
- 🏗️ Designed with scalable backend architecture and deployed locally using Docker and Kubernetes.

**Tech Stack:** Next.js | Spring Boot | REST APIs | PostgreSQL | WebSockets | MediaMTX | Docker | Kubernetes

🔗 [View Repository](https://github.com/KaranPushes/StreamNova)

---

### 🤖 2. LearnMate AI
An AI-powered PDF assistant that allows users to upload documents and interact with their content through intelligent question answering using Retrieval-Augmented Generation (RAG).

- 📄 Upload PDFs and ask questions about their content.
- 🧠 Uses RAG to retrieve relevant document context.
- 🔍 Generates context-aware answers using Google Gemini.
- 🗄️ Uses ChromaDB for vector storage and semantic retrieval.
- 🐳 Containerized with Docker and automated builds using GitHub Actions.

**Tech Stack:** Python | Streamlit | LangChain | ChromaDB | Google Gemini | Docker | GitHub Actions

👥 Collaborative project built with [Mayank Mehta](https://github.com/mayankmehta19032003).

🔗 [View Repository](https://github.com/mayankmehta19032003/LearnMate-AI)

---

### 🎵 3. YAMA – Yet Another Music App
A personal music streaming application inspired by Spotify, featuring customizable, section-aware music playback.

- 🎧 Custom playback intervals to play specific sections of songs.
- 📱 Mobile application built using React Native and Expo.
- ⚙️ Spring Boot backend for music management and streaming.
- 🚀 HTTP Range Requests for efficient audio streaming.
- 💾 Progressive caching for smoother playback.
- 🎼 Exploring automated music importing through Savify.

**Tech Stack:** Java | Spring Boot | React Native | Expo | PostgreSQL | Docker

🔗 [View Repository](https://github.com/KaranPushes/YAMA-Yet-Another-Music-App)
